# Between Seconds — Prototype 6 / Distinct Combat

Construct 3 Free + модульный TypeScript. Рабочая папка: `/Users/glebcejlonskij/Desktop/проекты/betweenseconds`. Версия **0.6.0.0**.

## Запуск

```sh
npm ci
npm run typecheck
npm run build
npm test
npm run package
python3 tools/validate_project.py
```

Заново откройте **эту папку проекта** в Construct либо `dist/BetweenSeconds-Prototype6.c3p`. Старый открытый проект/предпросмотр не перечитывает внешние изменения. F4 / Fn+F4 запускает проект: меню → «Начать» → выбор оружия → Tutorial. После обучения проходите в нарисованную арку справа. В основной кампании 15 комнат: 13 на основном пути, 2 необязательных тайника; пять областей, три стража и три основных босса. Используются два физических макета Construct, фон и состав комнаты меняет TypeScript.

## Управление и оружие

- WASD — движение; Space + WASD — рывок.
- ЛКМ — атака в сторону курсора. Направление фиксируется на время замаха.
- E — временной импульс: очистка угроз и урон; убийство восполняет заряд.
- Q — выбор доступного оружия на паузе; M — карта; ESC — пауза.
- F — сундук/лечение рядом с ним; R — повтор текущей комнаты; H — обучение.
- ⛶ / настройки — полный экран, если браузер разрешает. Окно масштабируется под экран.

Перед стартом доступны клинок (быстрый ближний бой), молот (2 урона, долгий замах и пробивание щита Бастиона) и лук (дистанция, без взмаха и отражения пуль). Молот, лук и последующие предметы имеют отдельный видимый спрайт в руке; исходные изображения героя сохранены. Удар молота и клинка Цветения анимируется отдельным предметом; это ещё не полный авторский набор поз рук под каждое оружие.

После Цветения выбирается **одно**: его широкий клинок или четвёртое сердце с восстановлением 1 HP. После Эха — пробивающее копьё или резерв из двух зарядов E с увеличенной областью. Награды не выдаются/не экипируются автоматически. Q позволяет вернуться к любому открытому оружию. Сундуки дают валюту и 1 HP; повторное F позволяет купить 1 HP за 3 осколка памяти. Повтор комнаты не позволяет фармить уже взятые награды и память. Нет сохранений между закрытиями игры или отдельного NPC-магазина.

## Бой и продвижение

Время идёт при реальном перемещении или действии. В покое стоят враги, снаряды, подготовка атак и вражеские эффекты; таймер неуязвимости также использует мировое время. Подготовка показывает заполненный след/область на земле; после выпуска заряда этот след исчезает. Стрелы, призмы, копья и иглы анимированы.

| Противник | Атаки и защита |
|---|---|
| Лучник | Направленная стрела, нативная Sine ограничена скоростью и укрытиями |
| Охотник | Предупреждённый стальной выпад, без лепестков |
| Бастион | Щит и удар молотом по земле; тяжёлый удар пробивает щит, E нарушает защиту |
| Стремник | Быстрый выпад и окно восстановления |
| Безликий Осколок | Зеркальные иглы, отмеченное перемещение, скрытие; E проявляет |
| Цветение | Копьё, широкие взмахи, веера лепестков и последовательные бутоны |
| Эхо | Призматические кольца, перекрёстные разломы, сходящиеся к захваченной точке призмы |
| Регент | Копья, королевский взмах, печати и перекрёстные лучи |

На 65% и 30% HP у основных боссов меняются набор/порядок атак и импортированный набор Idle/Walk/Windup/Attack: иные силуэты, плащи, броня, ореолы. Переход фазы отменяет старую подготовку и угрозы этого босса. Цветочные эффекты принадлежат Цветению и его оружию.

Проход открывается после зачистки. Маленькие часы на полу — **необязательная валюта**, они не блокируют выход. Переход — вход в существующую арку и затемнение; нет плавающего портала или приставной решётки. У закрытой арки показывается число оставшихся угроз. Только у развилки появляется выбор пути. Поражение показывает компактное окно, источник последнего попадания и повтор комнаты.

Пять областей передают историю окружением: живой сад → пустой город → расколотый архив → заражённая цитадель → источник с печатями, направленными внутрь. Пары цветных/замороженных фонов — черновые иллюстрации и требуют проверки совпадения деталей. Финальный Регент пока не нарушает остановку времени.

## Разработка и графика

`scripts/main.js` собирается из `src/main.ts`, вручную его не редактировать. `npm run dev` включает пересборку при изменениях. Два макета, по два слоя, 20 типов объектов, без новых дополнений. Бандл упакован в один файл для Free.

Повторный импорт (Python + Pillow):

```sh
python3 tools/import_hero.py
python3 tools/import_hero_locomotion.py
python3 tools/import_core_art.py
python3 tools/import_neon_art.py
python3 tools/import_designer_run.py
python3 tools/import_polish.py
python3 tools/import_combat_v4.py
python3 tools/import_journey.py
python3 tools/import_combat_v6.py
```

Последний импорт обязателен. Исходные атласы/промпты новой встроенной `image_gen` — `art/combat-v6/`; предыдущие — `art/journey/`, `art/combat-v4/`. Это AI-черновики, не работа дизайнера. Оригинальные 16 кадров бега и 20 кадров атак дизайнера проверяются на попиксельное совпадение. Контуры, читаемость и новые формы требуют художественной проверки.

Текущие результаты и незаполненные ручные сценарии — [COMBAT_IDENTITY_TESTING.md](COMBAT_IDENTITY_TESTING.md). Предыдущие отчёты сохранены как история. Общий код в main; новые задачи делайте в ветках от актуального origin/main и объединяйте через PR.
