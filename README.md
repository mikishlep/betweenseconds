# Between Seconds

Небольшая 2D top-down action игра, разрабатываемая в рамках командного университетского проекта.

## Об игре

Главная механика: время движется вместе с игроком. Пока персонаж стоит, окружающий мир замирает. При движении время возобновляется.

Игроку предстоит проходить уровни, уклоняться от атак, сражаться с противниками и боссами, используя остановку времени для планирования действий.

## Управление

- **WASD**: передвижение
- **Space + WASD**: рывок

## Технологии

- Construct 3
- TypeScript
- esbuild
- Git / GitHub

## Локальная разработка

```bash
npm install
npm run dev
```

Открыть `project.c3proj` в Construct 3 и запустить предпросмотр.

Для разовой сборки:

```bash
npm run build
```
