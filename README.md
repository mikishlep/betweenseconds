# Between Seconds — Prototype 3 / Neon Combat Core

Короткое прохождение: **Tutorial → Двор Цветения → Первая Трещина → Страж Разлома → итог и новое прохождение**. Это четыре столкновения на двух физических макетах Construct: основная арена переиспользуется с разным составом врагов и палитрой. Новая сессия всегда начинается с Tutorial, включая F5 на другой карте.

Чтобы открыть выход, нужно **победить всех врагов и собрать два голубых фрагмента**. Герой получает 3 HP на старте каждой комнаты. Победа показывает оценку S/A/B по полученному урону и числу ударов; Enter продолжает прохождение. R перезапускает текущую комнату, H возвращает в обучение.

## Управление

- **WASD** — движение и направление взгляда.
- **Space + WASD** — рывок.
- **ЛКМ** — настоящий удар в последнем направлении WASD: сектор перед героем, 1 урон, дальность 90 px; стены блокируют удар. Перед собой можно сбить вражеские заряды. Курсор пока не задаёт направление.
- **E** — временной импульс: очищает пули в радиусе 165 px, наносит 1 урон видимым врагам в области и даёт короткую защиту. Один заряд; победа над врагом восстанавливает его до одного.
- **Enter** — после победы перейти дальше; после последней комнаты начать прохождение заново.
- **R** — повторить текущую комнату, **H** — обучение.

Мир движется при фактическом перемещении **или во время атаки/импульса**. Пока герой стоит и не действует, пули, вражеские таймеры, предупреждения и движение заморожены. Игрок и его анимации используют независимые часы. Защита после попадания — 1 секунда времени мира; пауза её не расходует. Рывок сам по себе не даёт неуязвимости.

## Бой и оформление

Стрелок двигается по нативной Sine и предупреждает линией прицеливания. Охотник приближается и делает рывок после предупреждения; укрытия блокируют его движение. Мини-босс выпускает кольца и прицельный заряд: на половине HP кольца учащаются и растут с 8 до 12 снарядов. Удары, E и сбивание пуль дают реальные тактические способы пройти бой.

Оформление — **псевдо-2.5D**, не новая 3D-физика: наклонённый каменный двор, передние грани укрытий, тени и порядок отрисовки по положению ног. Границы коллизий согласованы с внешней стеной фонового двора. В движении окружение цветное, в стоп-кадре используется отдельный почти монохромный вариант. Угрозы остаются малиновыми, действия героя и траектории — голубыми.

Вместо геометрических вспышек — шестикадровые неоновые взмахи, волна импульса и заряды с белым ядром, цветным следом и аддитивным свечением. Они не меняют размеры хитбоксов. Новое окружение, враги и эффекты — AI-черновики по присланным концептам. Исходные атаки дизайнера и герой сохранены. Покой и ходьба из предыдущей итерации тоже остаются отдельными AI-доработками для сверки с дизайнером.

## Разработка

Node.js 22+, npm, Python 3 для упаковки. Новые зависимости Node не добавлялись.

```sh
npm ci
npm run typecheck
npm run build
npm test
npm run package
```

`npm run dev` пересобирает JS при изменении TS. Исходники модульные; вручную `scripts/main.js` не редактировать. Сборка удаляет пробелы и объединяет TS в один JS для лимитов Free. Два макета, по два слоя, ноль событий и шейдерных эффектов, никаких сторонних дополнений; свечение создаётся ресурсами и штатным режимом смешивания.

Повторный импорт графики (только для разработчика, нужен Pillow):

```sh
python3 tools/import_hero.py
python3 tools/import_hero_locomotion.py
python3 tools/import_core_art.py
python3 tools/import_neon_art.py
```

Порядок важен: последний шаг подключает актуальную наклонную площадку и неоновые эффекты поверх базового импорта. Повторная генерация изображений не нужна: исходники и промпты сохранены в `art/hero/` и `art/core/`. Скрипты выполняют нарезку и нормализацию кадров; геометрические тени, грани стен и предупреждения авторуются кодом.

## Основные модули

- `src/game/Rooms.ts` — три боевые комнаты, Tutorial и прогресс прохождения.
- `src/game/CombatSystem.ts` — здоровье/роли врагов, попадания, снаряды, предупреждения, импульс и сбивание.
- `src/combat/PlayerActions.ts` — приём кликов, задержка удара, E и окно активности времени.
- `src/systems/TimeController.ts` — движение и действия как часы мира; безопасная работа после гибели врагов.
- `src/world/Depth.ts` — тени, грани укрытий и порядок отрисовки.
- `src/world/Effects.ts`, `Presentation.ts` — неоновые кадры и смена состояния окружения.
- `src/player/` — движение, рывок, анимации героя.
- `CORE_LOOP_TESTING.md` — текущая проверка и ручные сценарии. `PROTOTYPE_TESTING.md` хранит историю ранних прототипов и незаполненные разделы команды.

Автотесты выполняют логику и точку входа с заменителями API Construct. Они не подтверждают работу нативного движка или финальное качество графики. В этой сессии удалось открыть отдельный Construct в Chrome, но при попытке открыть сборку управление браузером дважды завершилось тайм-аутом; настоящий предпросмотр этой версии не подтверждён.

## Работа командой

Общая версия — в `main`. Для новой задачи создавайте ветку от актуального `origin/main`, затем pull request в `main`. Второму разработчику, сохранив свои незакоммиченные изменения:

```sh
git fetch origin
git switch ser1-dev
git merge origin/main
```

История не переписывается, force push не нужен. Эта итерация не реализует весь объём ГДД: хаб, реплей, 10–15 отдельных комнат, полный набор канонических боссов, оружие с патронами и сюжетные сцены остаются следующими этапами.
