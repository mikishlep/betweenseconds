# Between Seconds — Prototype 5 / Journey

Проект Construct 3 Free + модульный TypeScript. Рабочая папка: `/Users/glebcejlonskij/Desktop/проекты/betweenseconds`.

## Прохождение

Обучение → сад → город → архив → цитадель → источник аномалии. В маршруте 15 комнат: 13 на основном пути и 2 необязательных тайника. Две физические сцены Construct переиспользуются с разными фонами, укрытиями, врагами и задачами. Это фиксированный маршрут, не процедурный генератор комнат.

Перед Цветением, Эхом и Регентом стоят отдельные стражи:
- Каменный Бастион держит щит перед собой. Обходите его во время замаха; E нарушает защиту.
- Багровый Стремник останавливается вне обычной дистанции удара, готовит быстрый выпад и открывается после него.
- Безликий Осколок перемещается между отмеченными точками и ненадолго скрывается. E проявляет его.

Основные боссы подключены к кампании: Цветение — взмахи, вееры лепестков, бутоны; Эхо — кольца с безопасным сектором, разломы и перемещение; Регент — вееры, разломы, широкий удар и их сочетания. На 65% и 30% HP меняются фаза, темп, состав угроз, цвет тела и ореол. Это изменения одобренных спрайтов цветом/эффектами; отдельных полных наборов анимации для каждой фазы пока нет.

Выход открывается после зачистки и двух временных фрагментов. В тайниках фрагменты не нужны. При входе в выход появляется экран продолжения с явными кнопками и выбором ответвления. Поражение даёт кнопку повтора комнаты и возврата в меню.

За Цветение выдаётся Лепестковый клинок с большей дальностью; за Эхо — дальнобойное Копьё Эха. Q переключает открытое оружие. Сундуки дают 3 осколка памяти и восстанавливают 1 HP; повторное F у открытого сундука позволяет купить 1 HP за 3 осколка. Награды и сундуки нельзя фармить перезапуском. HP переносится между комнатами; повтор боевой комнаты начинает её с 3 HP. Отдельного магазина, NPC-хаба, инвентаря и сохранения между закрытиями игры нет.

## Управление

- WASD — движение и направление взгляда.
- ЛКМ — удар текущим оружием; курсор пока не задаёт направление.
- Space + WASD — рывок.
- E — импульс очистки/урона, один заряд; победа над врагом возвращает заряд.
- Q — следующее открытое оружие.
- F — сундук / восстановление рядом с ним.
- M — карта пути, останавливает игру.
- Enter — основной путь после прохождения; альтернативный тайник выбирается кнопкой.
- R — повтор комнаты, H — обучение, ESC — пауза.
- ⛶ / настройки — запрос полного экрана. Браузер может отказать; обычное окно масштабируется под доступную площадь.

Время мира идёт при перемещении или атаке, иначе стоят враги, снаряды, подготовка и вражеские эффекты. Таймер защиты после попадания использует мировое время. Арчеры сохраняют нативную Sine, но фаза останавливается во время подготовки, а смещение ограничено скоростью и укрытиями. Это устраняет скачки после выстрела.

## Оформление и запуск

Пять новых областей рассказывают об изменении мира окружением: целый сад, закрытый город, разрушенный архив, заражённые знамёна, печати у источника. У каждой области есть цветной и замороженный фон. Графика пока черновая; пары фонов требуют художественной проверки совпадения мелких деталей. Важные угрозы остаются малиновыми, действия героя голубыми. Обычные враги компактные; боссы крупнее. Авторский герой, атаки и 16 кадров бега дизайнера сохранены.

Укрытия — низкие каменные баррикады с отдельной малой коллизией и видимой передней гранью. В макете редактора видны технические коллизии; финальный вид формируется при запуске.

После внешних изменений заново откройте **эту папку проекта**, выберите проект версии **0.5.0.0**, запустите Preview project (F4 / Fn+F4), нажмите «Начать». Старый предпросмотр не перечитывает новые файлы. Отдельный файл: `dist/BetweenSeconds-Prototype5.c3p`.

## Разработка и проверка

```sh
npm ci
npm run typecheck
npm run build
npm test
npm run package
```

`npm run dev` следит за TypeScript. `scripts/main.js` собирается автоматически, вручную его не редактировать. Два макета по два слоя, 20 типов объектов, без новых сторонних дополнений; JS упакован в один файл для Free.

Повторный импорт изображений требует Python + Pillow:

```sh
python3 tools/import_hero.py
python3 tools/import_hero_locomotion.py
python3 tools/import_core_art.py
python3 tools/import_neon_art.py
python3 tools/import_designer_run.py
python3 tools/import_polish.py
python3 tools/import_combat_v4.py
python3 tools/import_journey.py
```

Порядок важен. Исходные атласы и промпты встроенной image_gen находятся в `art/journey/`, `art/combat-v4/`, `art/core/`. Это AI-черновики; они не выдаются за работу дизайнера.

Актуальные результаты и незаполненные проверки командой — в `JOURNEY_TESTING.md`. Старые отчёты в CORE_LOOP_TESTING.md и PROTOTYPE_TESTING.md сохранены как история.

Общий код в main. Для задачи создавайте ветку от актуального origin/main и объединяйте через pull request. История не переписывается, force push не используется.
