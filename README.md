# Between Seconds — Prototype 2

Одна арена: соберите **2 голубых фрагмента** и войдите в **зелёный выход**. Противник движется по синусоиде и стреляет в игрока. Время противника, пуль и стрельбы идёт только при фактическом перемещении игрока. У персонажа 3 HP; попадание пули или касание противника отнимает 1 HP. После попадания действует защита в течение одной секунды игрового времени. Рывок не даёт отдельной неуязвимости.

- **WASD** — движение.
- **Space + WASD** — рывок; направление фиксируется в момент нажатия, перезарядка 0,6 секунды реального игрового времени игрока.
- **R** — начать заново в любой момент, включая остановку времени, победу и поражение.
- Оранжевый наконечник показывает направление пули. Тонкая линия перед ним остаётся видимой в остановленном времени и обрезается ближайшей стеной. Это подсказка направления, а не обещание попадания в движущуюся цель.

## Запуск

1. Откройте [Construct 3](https://editor.construct.net/) в Chrome/Edge.
2. **Открыть → Файл** → `dist/BetweenSeconds-Prototype2.c3p`.
3. Запустите предпросмотр (кнопка ▶ / F5), кликните по игре для фокуса клавиатуры.
4. После обновления проекта закройте старый предпросмотр и заново откройте свежий `.c3p`. Уже открытая копия автоматически не обновляется.

Для работы с исходниками можно выбрать **Открыть → Папка проекта** и указать папку `betweenseconds` с `project.c3proj`. Не выбирайте `src` или `scripts` отдельно.

## Разработка и проверка

Нужен Node.js 22 или новее и Python 3 для упаковки. Проверено на Node 22.20.0 / npm 11.10.0.

```sh
npm ci
npm run typecheck
npm run build
npm test
npm run package
```

`npm run dev` пересобирает JS при изменениях. Переоткройте проект/предпросмотр в Construct после изменения файлов. При передаче проекта повторите `npm run build` и `npm run package`.

Готовый проект: `dist/BetweenSeconds-Prototype2.c3p`. Это ZIP-контейнер Construct, созданный из настоящего `project.c3proj`, макета, типов объектов и ресурсов. Упаковщик не включает Git, node_modules или пользовательские настройки редактора.

## Структура

- `src/player/PlayerController.ts` — ввод перед шагом EightDir, рывок.
- `src/systems/TimeController.ts` — фактическое перемещение и остановка мира.
- `src/game/` — состояния, стрельба, столкновения, фрагменты, выход, перезапуск.
- `src/ui/Hud.ts` — компактный HUD без фоновой панели.
- `scripts/main.js` — собранный файл для Construct; вручную не редактировать.
- `art/prototype/*.svg` — простые временные формы; `tools/create_prototype_art.py` создаёт их PNG для Construct (нужен Pillow, только для пересоздания графики).
- `tests/` — проверки логики с заменителями API движка и проверка структуры проекта. Снимок первого прототипа из коммита `aa9c42c` хранится в `tests/fixtures/prototype1`.
- `PROTOTYPE_TESTING.md` — результаты, ограничения проверки и незаполненные формы команды.

## Construct Free

Один макет, два слоя, ноль событий, ноль эффектов и веб-шрифтов. Никаких сторонних дополнений. Модульные TS-исходники собираются esbuild в один JS с удалёнными пробелами; и `build`, и `dev` используют этот формат. Не импортируйте `src/` в Construct дополнительно к `scripts/main.js`.

Учтены опубликованные ограничения Free на число строк кода; окончательную совместимость, камеру, Solid и внешний вид нужно подтвердить настоящим предпросмотром. Автотесты не заменяют запуск Construct. В этой сессии редактор открылся, но автоматический выбор локального файла не сработал. Скриншот пользователя показывает прохождение ранней сборки до победы; обновлённое оформление ещё требует проверки в движке.
