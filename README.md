# Between Seconds — Prototype 2

Актуальная версия от 14 ноября 2026: любая новая игровая сессия, включая F5 на основной арене, сначала открывает **Tutorial**, затем **Enter** после победы переводит на основную арену. Это явный стартовый маршрут в main.ts, а не зависимость от открытой вкладки редактора. Обучение засчитывает реальное движение, остановку и рывок. До шага сбора фрагментов урон и сбор отключены. **R** повторяет текущий уровень; **H** из основной арены открывает обучение заново.

**ЛКМ** проигрывает анимацию атаки в последнем направлении WASD. Урона мечом пока нет. Четыре спрайтшита дизайнера по пять кадров 64×64 сохранены без изменений в `art/hero/source/`; импорт: `python3 tools/import_hero.py` (для повторного импорта нужен Pillow). Исходные Attack и однофреймовые Idle сохранены. Новые черновые `Breathe` (покой, 4 FPS) и `Walk` (ходьба, 8 FPS) добавлены отдельно для четырёх направлений, по четыре кадра. Они созданы встроенной генерацией изображений по авторским референсам и требуют визуальной сверки дизайнером; это не новые кадры самого дизайнера. Исходный атлас: `art/hero/generated/hero-locomotion-v2.png`, спецификация и промпты: `art/hero/generation.json`, воспроизводимый импорт: `python3 tools/import_hero_locomotion.py`. Импорт только нарезает сетку, масштабирует nearest-neighbor до 64×64 и выравнивает голову через origin кадров, без перерисовки пикселей. Визуал 64×64 отделён от невидимого хитбокса Player 28×28: меч и прозрачные поля не влияют на стены и попадания. Анимация ходьбы включается только при фактическом перемещении; итоговый экран замораживает текущую позу.

Ветка `ser1-dev` объединена с локальным `main` без переписывания истории. Исправлены переключение подсказок по одному Space и отсутствие перехода на арену; пустой «Макет 2» удалён. Последовательность обучения теперь находится в модульном `src/game/TutorialController.ts`, TutorialEvents оставлен пустым. Сейчас в проекте два макета, по два слоя, один собранный JS и ноль событий.

Для следующих задач: отдельная ветка от актуального `origin/main` → pull request в `main` → проверка → merge. Второму разработчику для обновления своей ветки, предварительно сохранив незакоммиченные изменения:

```sh
git fetch origin
git switch ser1-dev
git merge origin/main
```

Это добавляет общие изменения без force push. Изменения TypeScript всегда собирать через `npm run build`; `scripts/main.js` вручную не редактировать.

Одна арена: соберите **2 голубых фрагмента** и войдите в **зелёный выход**. Противник движется по синусоиде и стреляет в игрока. Время противника, пуль и стрельбы идёт только при фактическом перемещении игрока. У персонажа 3 HP; попадание пули или касание противника отнимает 1 HP. После попадания действует защита в течение одной секунды игрового времени. Рывок не даёт отдельной неуязвимости.

- **WASD** — движение.
- **Space + WASD** — рывок; направление фиксируется в момент нажатия, перезарядка 0,6 секунды реального игрового времени игрока.
- **R** — начать заново в любой момент, включая остановку времени, победу и поражение.
- Оранжевый наконечник показывает направление пули. Тонкая линия перед ним остаётся видимой в остановленном времени и обрезается ближайшей стеной. Это подсказка направления, а не обещание попадания в движущуюся цель.

## Запуск

1. Откройте [Construct 3](https://editor.construct.net/) в Chrome/Edge.
2. **Открыть → Файл** → `dist/BetweenSeconds-Prototype2.c3p`.
3. Запустите **предпросмотр проекта (F4)**, затем кликните по игре для фокуса клавиатуры. На Mac может понадобиться Fn+F4. Кнопка ▶ и F5 сначала запускают текущий макет, но явная стартовая маршрутизация игры переводит новую сессию в Tutorial. После перехода Enter и при рестарте R принудительного возврата нет; H возвращает в обучение вручную.
4. После обновления проекта закройте старый предпросмотр и заново откройте свежий `.c3p`. Уже открытая копия автоматически не обновляется.

Для работы с исходниками можно выбрать **Открыть → Папка проекта** и указать папку `betweenseconds` с `project.c3proj`. Не выбирайте `src` или `scripts` отдельно.

## Разработка и проверка

Нужен Node.js 22 или новее и Python 3 для упаковки. Проверено на Node 22.20.0 / npm 11.10.0.

```sh
npm ci
npm run typecheck
npm run build
npm test
npm run package
```

`npm run dev` пересобирает JS при изменениях. Переоткройте проект/предпросмотр в Construct после изменения файлов. При передаче проекта повторите `npm run build` и `npm run package`.

Готовый проект: `dist/BetweenSeconds-Prototype2.c3p`. Это ZIP-контейнер Construct, созданный из настоящего `project.c3proj`, макета, типов объектов и ресурсов. Упаковщик не включает Git, node_modules или пользовательские настройки редактора.

## Структура

- `src/player/PlayerController.ts` — ввод перед шагом EightDir, рывок.
- `src/systems/TimeController.ts` — фактическое перемещение и остановка мира.
- `src/game/` — состояния, стрельба, столкновения, фрагменты, выход, перезапуск.
- `src/ui/Hud.ts` — компактный HUD без фоновой панели.
- `scripts/main.js` — собранный файл для Construct; вручную не редактировать.
- `art/prototype/*.svg` — простые временные формы; `tools/create_prototype_art.py` создаёт их PNG для Construct (нужен Pillow, только для пересоздания графики).
- `tests/` — проверки логики с заменителями API движка и проверка структуры проекта. Снимок первого прототипа из коммита `aa9c42c` хранится в `tests/fixtures/prototype1`.
- `PROTOTYPE_TESTING.md` — результаты, ограничения проверки и незаполненные формы команды.

## Construct Free

Два игровых макета, по два слоя, ноль событий, ноль эффектов и веб-шрифтов. Никаких сторонних дополнений. Модульные TS-исходники собираются esbuild в один JS с удалёнными пробелами; и `build`, и `dev` используют этот формат. Не импортируйте `src/` в Construct дополнительно к `scripts/main.js`.

Учтены опубликованные ограничения Free на число строк кода; окончательную совместимость, камеру, Solid и внешний вид нужно подтвердить настоящим предпросмотром. Автотесты не заменяют запуск Construct. В этой сессии редактор открылся, но автоматический выбор локального файла не сработал. Скриншот пользователя показывает прохождение ранней сборки до победы; обновлённое оформление ещё требует проверки в движке.
