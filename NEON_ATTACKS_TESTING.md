# Prototype 7 — атаки, неон, лук и отдача

Версия проекта **0.7.1.0**, 14 ноября 2026. Рабочая папка: `/Users/glebcejlonskij/Desktop/проекты/betweenseconds`.

## Проверено

- TypeScript и `npm run build` проходят.
- **94/94** автоматических теста модулей, включая регрессии по новым скриншотам. Это тесты с подставным runtime, не полное прохождение Construct.

## Причины ошибок и изменения

| Наблюдение | Причина | Исправление |
|---|---|---|
| Стрелы оставались рядом с героем на шаге обучения с рывком | Strike уже создавал снаряды, а весь CombatSystem.update был выключен до завершения трёх шагов обучения | Полёт стрел обновляется с первого шага; ИИ врагов ждёт окончания подготовки. После окончания действия стрелы корректно замирают вместе с миром |
| Молот висел далеко от руки/над головой в покое | Смещённая точка вращения, постоянный боевой угол и крупный размер | Шарнир у руки, меньший размер, опущенная поза в покое и отдельный замах вокруг хвата |
| Молот слишком силён | Откат 0.85 s, замах 0.24 s, длинное окно оглушения | Откат **1.5 s**, замах **0.4 s**, открытие щита **0.55 мировых секунд**; тяжёлых врагов не отбрасывает |
| Попадание по обычному врагу плохо видно | Прозрачность вместо цветовой реакции | Короткий красный цвет тела, искра попадания, отбрасывание стрелков/охотников/заклинателей; стены ограничивают смещение. Таймер Sine переносится с новой позицией, без возврата к старому центру |
| Неон пропал при борьбе с пересветом | Для всех эффектов отключили additive | Цветное резкое ядро с обычной альфой плюс отдельное ограниченное свечение/свет на полу. У камня свет слабее, у магии — выраженнее |
| Магические печати выглядели простыми квадратами | Техническая Sigil-маска | Отдельные шестикадровые печати Эха, Регента и Цветения с рунами, короной/затмением и лепестковым венком |
| Лучи были растянутыми снарядами, затем распались на прямоугольники | Сначала использовались алиасы картинок снарядов, затем короткие сегменты без бесшовного соединения | Новые **цельные** шестикадровые лучи 512×128; один основной спрайт на луч, равномерный масштаб, без плиток и стыков |
| У Цветения появился синий луч Эха (скриншот 22:58) | Ветка всех line-hazards по умолчанию вызывала рендерер Эха, включая RoseThrust | Только EchoBeam/RegentBeam используют лучи. RoseThrust использует свой шип. Отдельный тест запрещает чужой эффект у Цветения |
| Перед боссами повторялся один состав | В обычных комнатах использовались только лучник и охотник | В город добавлен тяжёлый страж с ударной волной, в архив — заклинатель со сферами; в цитадели и у источника новые сочетания четырёх ролей |
| Атаки различались главным образом размером | Одни формы использовались как разные эффекты | У Эха — реальные круговые/сходящиеся/орбитальные сферы и разломы; у Регента — орбитальные чёрные солнца, лучи, тёмные очаги с последующим выбросом сфер; у стражей — расширяющийся каменный фронт с безопасным центром |

Лепестковые снаряды остаются только у Цветения; лепестковый взмах героя относится к выбранному оружию Цветения. Стрелы имеют физический наконечник/древко, сферы — круглое ядро, иглы фантома и королевские копья — собственные формы. Новые анимации и арт в `art/combat-v7/`; точные промпты/происхождение встроенной image_gen — `generation.json`. Старые исходники сохранены.

## Проверка настоящего движка

Доступ к старому окну предпросмотра и редактору получен. При попытке открыть свежую сборку CUA сообщил о внешнем изменении окна, последующее чтение состояния завершилось таймаутом. **Запуск 0.7.1.0 в Construct агентом не подтверждён.** Скриншот пользователя с кусками луча зафиксировал реальную ошибку промежуточной сборки; он не используется как доказательство исправления.

Исправленные полные лучи и стрелы проверены как импортированные изображения. Для оценки всей композиции/освещения нужен живой предпросмотр. Открытый редактор хранит старые метаданные и изображения: для этой проверки заново открыть папку проекта или `dist/BetweenSeconds-Prototype7.c3p`, убедиться в версии **0.7.1.0**, затем F4.

## Ограничения

Свет — спрайтовая имитация свечения/отражения на полу, без настоящих динамических теней. Исходные позы героя не перерисованы под каждый хват. Новые спрайты — AI-черновики; согласование с дизайнером не выдумано. Финальный Регент пока соблюдает остановку времени. Полный нативный плейтест этой сборки и проверка производительности при большом количестве сфер остаются ручными.
