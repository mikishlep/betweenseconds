## Наблюдаемые проблемы и причины

| Проблема | Причина в прежнем коде/атласе | Изменение |
|---|---|---|
| Охотники выглядели как Цветение | Общий RoseSweep использовался для обычного выпада | SteelCut для охотника/Стремника; камень для Бастиона; призмы Эха; иглы фантома; копья Регента |
| Тонкие траектории | В 128×128 маске полоса занимала только часть высоты и ещё сжималась runtime | Маска Lane 128×32 с заполнением всей рабочей высоты; исчезает при выпуске |
| Фазы почти не меняли внешний вид | Одни позы с цветом и ореолом | Шесть отдельных наборов поз для фаз 2/3 трёх боссов; отмена старых угроз при переходе |
| Награда автоматически добавляла выстрел к удару | Автовыдача/экипировка и смешанный тип атаки | Явные карточки; чистый ближний или дальний бой; Q открывает выбор |
| Оружие выбиралось, но в руках всё тот же меч | Менялась логика, не визуал героя | Видимые молот/лук/клинок Цветения/копьё с собственным движением; для них не запускается исходный мечевой Attack |
| Бастион не получал урона молотом | Guard отсекал все виды оружия; не было пояснения блока | Молот наносит 2 урона через щит, прерывает подготовку и открывает на 0.9 мировых секунд; блок другого оружия объясняется |
| Попадание по крупному телу неудобно | Проверялась точка у ног вместо объёма корпуса | Для melee учитывается край нижней части тела, для стрел — прямоугольник корпуса; укрытия по-прежнему отсекают удар |
| Обрубок соседнего спрайта у Бастиона | Молот в исходном атласе пересекал границу двух ячеек | Границы извлечения Bulwark заданы по полному исходному замаху, остаток соседнего молота исключён |
| Сильный белый пересвет на светлом полу | Все эффекты использовали additive, включая камни/пыль | Normal alpha blending, ограниченная непрозрачность и затухание; малиновый/голубой цвет остаётся в самих спрайтах |
| Портал и приставная решётка не вписывались в арку | Отдельные декоративные объекты поверх нарисованного входа | Существующая арка + невидимый триггер; текст причины блокировки рядом; затемнение при переходе |
| Обязательные ромбы мешали проходу | Валюта входила в условие выхода | Маленькие анимированные часы; выход зависит от зачистки, не от сбора |
